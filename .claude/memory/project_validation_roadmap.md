# NJ Sandy quadtree — validation roadmap & sequencing logic (2026-06-02)

State: the ported notebook (X1 SnapWave + re-clipped CUDEM) runs end-to-end on the quadtree. MOTF spatial validation: **CSI 0.48, POD 0.54, FAR 0.17**. Shark River + Sandy Hook extent improved; two issues flagged (Shrewsbury under-flood + inland false alarms). See [[project-hm0-spike-rootcause]] for the run details and the xc/downscale/de-rotate notebook fixes.

## Core sequencing logic
- **Phase A items are POST-PROCESSING** (Phase-3 cells, no model rebuild) → cheap, do now.
- **Phase B items are ALL Phase-1 REBUILDS** (mesh / mask / bathymetry → regenerate sfincs.nc + subgrid, the ~13 GB step that repeatedly OOM'd/crashed the host this session). So BATCH them into ONE rebuild instead of paying that cost 4×.
- Do Phase A FIRST because it's free and tells us WHICH Phase-B changes are actually warranted (e.g. if Shrewsbury is mostly the L3-coverage artifact, the boundary/inlet surgery may be unnecessary).
- Each hydromt model.read() is multi-GB; do NOT load multiple copies in side-processes (that caused the crashes). Edit notebook cells as lightweight text; let the user run in their kernel.

## What X2 fixes vs not (why it anchors Phase B but isn't prioritized to fix the others)
X2 = extend the quadtree mesh SEAWARD to the ERA5 wave input points (Leijnse-style); waves enter in deep water and shoal/refract across the shelf, driving SFINCS at a coastal handoff instead of being injected at the z=−10 m edge.
- **X2 FIXES:** offshore zs 2Δx boundary ring; Sandy Hook gauge high-freq NOISE (same ring leaking into the gauge ~2.7 km away — NOT waves; verified uncorrelated with hm0, present pre-storm); paper-quality offshore wave transformation; and it SUBSUMES the SnapWave-param re-test (rebuilds the SnapWave setup anyway).
- **X2 does NOT fix:** Shrewsbury back-bay under-flood (back-bay hydrodynamics: inlets/estuary/boundary), inland false alarms (rain/river/numerical), disconnected mask patches, Asbury hm0 spikes (real steep nearshore bathy; maybe marginal).
- Therefore X2 is the VEHICLE for the batched Phase-B rebuild, not a fix for the back-bay/inland problems.

## PHASE A — cheap, now, no rebuild
1. **Mosaic the flood map L1+L2+L3 — RESOLVED 2026-06-02, the COVERAGE-ARTIFACT hypothesis is DISPROVEN.** Built the finest-wins mosaic mechanics (de-rotate L3 to north-up = target, reproject_match L2/L1, fill where L3 is NaN; peak ~4.8 GB, safe). Diagnostic against MOTF on the north-up grid: the 15.9 km² "model dry" miss is ENTIRELY inside the L3 footprint already — the mosaic adds **0.00 km² of new MOTF-wet land**. The L2/L1 fill is 35 M px of DEEP water (z<−8, channels/open estuary) that the flood map masks out (dep>−0.5) anyway; new shallow [−8,3] land is +0.3% (~0.4 km²), none of it MOTF-relevant. So the mosaic is a **near no-op for CSI/POD/FAR** and does NOT explain the miss. Why the earlier theory was wrong: the miss cells are LAND (dep>0) = estuary SHORE/marsh, which IS inside the surf_dune z∈[−8,3] L3 gate (so it's L3-covered); only the deep OPEN water is L2, and open water isn't scored (land_in = dep>0). **Verdict: the back-bay miss is GENUINE under-prediction → Phase B item 5 (back-bay boundary/inlets) IS warranted; the Shrewsbury question is settled = real, not coverage.** Miss breakdown: 14.5 km² bone-dry (hmax=NaN, no water at all — not thin-film), 1.4 km² sub-threshold thin-film; 13.9 km² (87%) back-bay vs 2.0 km² open/east.
2. **Diagnose false alarms — UPDATED 2026-06-02: total 3.8 km², almost ALL back-bay (3.6 km²), NOT inland-distributed as assumed.** Split ~half thin (0.15–0.30 m, compound rain/film) and ~half deep (>0.5 m) sitting on relatively HIGH ground (median DEM 5.1 m, p90 13.2 m) → DEM-pit / spurious-ponding candidates more than a coast-connected compound signal. Connectivity filter + depth threshold still the right cleanup. (The earlier "4 km² inland" framing was roughly right on magnitude but wrong on location — it's back-bay, co-located with the miss.)
3. **Shrewsbury verdict: SETTLED 2026-06-02 = REAL under-prediction, not coverage** (see item 1). Phase-B back-bay work (boundary/inlets) IS warranted.
